¿Cuál es la forma más cómoda para cambiar el color del título en 10 páginas?

Yo creo que la forma más cómoda es utilizar un archivo CSS externo, porque puedo cambiar el color en un solo archivo y el cambio se aplica a todas las páginas que lo tengan enlazado.

¿Por qué se desaconseja utilizar la primera forma?

Porque hay que escribir el estilo en cada elemento y si quiero cambiar algo tengo que modificarlo uno por uno. Además, el HTML queda más lleno y cuesta más mantenerlo organizado.
